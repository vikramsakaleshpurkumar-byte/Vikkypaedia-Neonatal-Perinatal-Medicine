# Vikkypaedia · Neonatal–Perinatal Medicine

Open **index.html** in Chrome or Edge. Keep this entire folder together. If using the ZIP, extract it fully before opening index.html. No installation, account, server, API key or internet connection is required for the course itself.

This course covers all 103 numbered chapters and both appendices in the supplied PDF. It adds a focused teaching layer to the full extracted reference text: **630 authored recall cards, 525 authored single-best-answer MCQs, 525 guided learning units and 22 progressive fictional cases with 66 staged decisions**. Every section has six cards and five MCQs. The five selected outcomes per module do not assess every fact in its source chapter.

## How to study

1. Choose a chapter or an editorial study pathway from the topic library.
2. Open its learning outcomes. Use All levels, Essentials, Clinical Application or Deep Dive where authored; unsupported levels are disabled explicitly.
3. Read a unit, try its question and inspect the feedback. Read source opens the exact cited PDF-page section. Try again retains the earlier attempt history.
4. In a progressive case, answer each decision before advancing. Later findings and the final reasoning debrief are withheld until the appropriate stage. Cases are fictional teaching exercises.
5. Use the chapter cards, quiz studio or visual spotter for later review. The quiz studio also offers a random 25-question block.
6. Expand Full source reader for the extracted chapter and original figure/table page views. Full extracted Markdown includes smaller source text and recovered diagram views. Check original layout before interpreting numeric tables, superscripts or footnotes.
7. Download the Anki TSV from Flashcards, or import anki_course.tsv directly into Anki as a tab-separated, HTML-enabled Basic deck. The third field is tags.

The seven modes are Learn & read, Neonatal atlas, Clinical features, Care & therapeutics, Flashcards, Quiz studio and Visual spotter. Clinical feature tags are navigation aids based on source mentions, not diagnostic probabilities. The neonatal atlas contains source-linked concepts, not a pathogen-only taxonomy.

## Progress and privacy

Guided attempts, reflections and card self-ratings are saved in this browser's local storage. They can disappear if browser data is cleared or a different browser/profile/location is used. Export my learning record downloads a JSON backup for your own records; automatic restore/synchronization is not implemented. Use no real patient identifiers in reflections. The course sends no learning data to a server and uses no remote fonts or analytics.

Guided practice intentionally reuses quiz items. Completion, repeated-item scores and self-rated card confidence are study records, not certification or an independent pre/post estimate of learning gain. Planning time estimates have not been measured in learners.

## Source and review limits

The supplied file is the 12th edition, published in 2024, with the publisher listing copyright 2025. It is a source-edition study course, not a current neonatal treatment protocol. See [Source credits](SOURCE_CREDITS.md) and [Source review notes](SOURCE_REVIEW_NOTES.md).

Source checking covered selected teaching passages and selected original renders. No independent neonatal specialist has reviewed all lessons, questions, drug information or tables. Additional care-mode narrative excerpts are labeled separately from model-source-checked teaching principles. Numeric regimen fragments are excluded from that matrix; original treatment tables remain reference material in the source reader.

Image extraction retains 1,153 raster placements and adds 318 diagram renders: **1,471 image views**, not a count of unique clinical figures. There are **1,095 original source-page views**. Caption assignment and vector bounds are automatic; 134 image placements still have unmatched caption metadata. Use their original source-page context. Some source figures carry embedded labels; the spotter is formative image recall, not a validated blind image examination.

All supplied PDF teaching pages (21–2156) are accounted for. Front matter pages 1–20 are explicitly outside teaching scope; source attribution is retained. Printed numbering jumps at 18 chapter boundaries, possibly from absent divider/blank pages. These are documented without inventing missing content. Completeness relative to the publisher's full print pagination/index is not established.

## Navigation and accessibility

Keyboard users can use the skip link, native controls and visible focus indicators. Space reveals a card; arrows move through cards;1/2 record self-ratings. Escape closes image zoom and the mobile drawer. Source images have context/captions, but complex diagrams do not all have human-authored long descriptions. Automated browser checks include narrow-screen layout, focus trapping and staged-case behavior; full screen-reader, contrast and WCAG conformance audits remain unperformed.
